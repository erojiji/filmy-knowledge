# Filmy Knowledge

A non-commercial, offline-first catalogue of Indian films, with Hindi and Telugu
as the first-class languages. It is a private project used for a private,
non-commercial film-auction game.

TMDB is used only to resolve film IDs and poster artwork for titles already
identified through Wikipedia, Wikidata and trade sources. The application does
not proxy or resell the TMDB API, does not expose a public TMDB search service,
does not use TMDB content for AI/ML training, and does not generate revenue.

This repository is the public project page for the TMDB API application. It
intentionally contains no catalogue data, no database schema, no fixtures and no
private evidence. The working data and releases are kept private.

This product uses TMDB and the TMDB APIs but is not endorsed, certified, or
otherwise approved by TMDB.
